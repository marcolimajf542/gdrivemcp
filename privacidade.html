Política de privacidade — GDriveMCP

Vigente desde 16/10/2026

O que é

O GDriveMCP é uma ferramenta de uso pessoal, executada apenas no computador do próprio dono, que acessa as contas Google Drive dele por meio da API oficial do Google, com autorização OAuth concedida por ele. Não é oferecida a terceiros e não possui servidores.

Dados acessados

  • Arquivos e metadados do Google Drive das contas que o próprio dono autorizou (escopos drive.readonly e, quando ele habilita escrita, drive).
  • O endereço de e-mail de cada conta conectada, para identificá-la.

Como os dados são usados

  • Apenas para atender pedidos do próprio dono: procurar, ler, baixar e organizar os arquivos dele, e arquivar documentos fiscais da própria empresa.
  • Quando o dono pede ao assistente Claude Code para ler um arquivo, o conteúdo é enviado ao modelo de IA dentro da sessão do próprio dono, como parte do pedido dele.
  • Os dados não são vendidos, compartilhados com terceiros, usados para publicidade nem para treinar modelos de IA de uso geral.

Armazenamento e segurança

  • As credenciais de acesso (tokens OAuth) ficam no Gerenciador de Credenciais do Windows do computador do dono. Não são enviadas a nenhum servidor do aplicativo.
  • Arquivos baixados ficam somente no computador do dono.

Uso limitado

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.

Como revogar o acesso

A qualquer momento em myaccount.google.com/connections → GDriveMCP → Remover acesso. As credenciais locais também podem ser apagadas pela própria ferramenta.
